# TalentProof — Team Page

A pixel-perfect, responsive "Our Team" webpage for **TalentProof**, built with semantic HTML5, modern vanilla CSS, and vanilla JavaScript.

## Features
- **Visual Design**: Sleek dark/light aesthetic matching modern SaaS standards.
- **Team Roles & Responsibilities**: 5 team cards showcasing core leads (Product & Research, Tech, AI & Assessment, Design & UX, Product & Technology).
- **Interactive Details**: Clickable member cards that reveal comprehensive role responsibilities in a frosted-glass modal.
- **Principles Banner**: "How We Work Together" principles section with custom SVG icons.
- **Zero Dependencies**: Pure HTML, CSS, and JS with zero build steps needed.

## Quick Start
Open `index.html` directly in any browser, or run a local server:
```bash
python -m http.server 5173
```
Then visit `http://localhost:5173`.
